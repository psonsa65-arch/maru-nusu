# Project Blueprint

## Overview

A simple "Hello World" web application to demonstrate basic web development concepts and showcase the AI's capabilities.

## Current State

*   `index.html`: Basic HTML structure with a title, a heading, and a button.
*   `style.css`: Minimal styling.
*   `main.js`: Empty.

## Plan for Current Change

*   **Goal:** Make the application more interactive.
*   **Steps:**
    1.  Modify `index.html` to add IDs to the heading and the button for easier DOM manipulation.
    2.  Remove the inline `onclick` handler from the button.
    3.  In `main.js`, add an event listener to the button.
    4.  When the button is clicked, the event listener will change the text content of the heading.
